## Present Flame (Blog)

**Present Flame (Blog)**은 단순한 글 저장소가 아닙니다. 
기성 플랫폼의 상업성과 데이터 종속성에서 벗어나, 창작자가 온전히 자신의 사유를 통제하고 '불꽃'을 기록하기 위해 설계된 **독립적인 디지털 거점**입니다.

### 핵심 가치 (Core Values)
*   **Ownership:** 데이터와 디자인을 플랫폼에 의존하지 않고 온전히 소유함.[^1]
*   **Performance:** Astro의 정적 사이트 생성(SSG)[^2] 기술을 활용하여 불필요한 자바스크립트를 배제하고 압도적인 속도를 구현함.
*   **Philosophy in Design:** '시지프'와 '불꽃'이라는 개인 철학을 UI 전반(날짜 아이콘, 애니메이션 등)에 녹여내어 브랜딩함.

### 기술 스택 (Tech Stack)
*   **Framework:** Astro 5.0 & Svelte 5
*   **Styling:** Tailwind CSS & Stylus
*   **Icons:** Material Symbols (Customized)
*   **Deployment:** [Cloudflare Pages](https://pages.cloudflare.com/)

### 주요 특징 (Features)
*   **Custom Category Structure:** 3차까지 확장 가능한 계층형 카테고리와 아코디언 메뉴를 직접 구현함.
*   **Dynamic Metadata:** 창작자의 기록 행위를 강조하기 위해 커스텀 아이콘 및 메타 정보 시스템을 구축함.
*   **Clean Portfolio:** 블로그 일지와 분리된 독립적인 프로젝트 쇼케이스 공간을 마련함.

[^1]: Medium, Tistory 등의 플랫폼은 서비스 정책 변경에 따라 데이터가 삭제되거나 접근이 제한될 위험이 있음.
[^2]: Static Site Generation. 빌드 타임에 HTML을 미리 생성하여 서버 부하를 줄이고 로딩 속도를 비약적으로 높이는 기술.
